Pricing follows the risk. Run cost covers every line: both run teams, cloud servers (app servers, database, cache, storage and CDN, firewall, logs, backups, non-production), tooling and security, team software (Claude Max for every team member, GitHub, Jira; Figma in the build), the AI model, and LINE and SMS. IRIS carries the date risk, so implementation is a fixed fee with a premium. The client pays per enrolled employee, so cost scales with waves. Wave 1 runs below cost for three months (about THB 76 per head against a THB 39 price); the 20,000 minimum from wave 2 caps that exposure if later waves slip. The run team is dedicated because this is the platform's first client, and contingency is 15% because the fee is fixed. The client's own time (SMEs, champions, learning hours) is not priced; it comes from existing training hours. Not time-and-materials: the client would carry the date risk. Not outcome-only: there is no baseline yet. Value assumptions (shrink, internal fills, L&D redirection) are planning numbers to validate with the client's finance team in weeks 1-2.
