Source: Thai PDPA (s.28/29 cross-border transfers, PDPC DPIA guidance) · production decisions need client counsel and DPO sign-off

8

Privacy is on the critical path, so it starts in week 1: the DPIA is done by week 3 and the security pack goes to IT in week 2. The coach is built so that the riskiest data never reaches the model at all: identity numbers are masked, salary and other employees' records are excluded; only the employee's own development scores may be supplied. Each offshore LLM call is treated as a cross-border transfer (s.29 safeguards). Production safeguards still need validation.
