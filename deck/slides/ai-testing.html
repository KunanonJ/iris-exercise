4 · AI design: testing and running cost

Every release passes an eval gate; at scale the coach costs about THB 6 per active user a month

Eval set (weeks 3-9). 300-500 Thai/English cases per persona and BU: normal questions, bait for made-up courses, and red-team attacks (colleague data, pay, injection, wellbeing, PII). Built with BU SMEs and native Thai reviewers.

Release gate (every prompt or model change). 100% of red-team cases handled safely · 95%+ grounded (LLM judge + SME sample) · 90%+ correct citations · Thai quality 4/5+ · 100% in the user's language.

Friendly pilot (weeks 9-10). 300-500 users give thumbs up or down; SMEs review flagged answers every week.

In production. We track escalation rate, "no source" rate, CSAT and cost per user, with a weekly sample review.

Proof from the prototype: a 31-case harness runs the real code path. It caught a Thai bug: the name นภา matched inside แผนภายใน (no spaces in Thai), which blocked a normal question. Fixed with word-boundary rules; now 31 of 31 pass.
