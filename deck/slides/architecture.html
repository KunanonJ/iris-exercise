Build, configure or buy

  • Build (IRIS IP, reused across clients): skills graph, assessment, path engine, coach and guardrails, approvals, dashboards, test harness.
  • Configure (client already has): sign-in, both LMSs, HR exports, LINE account, BI tool, cloud landing zone.
  • Buy: AI model access (enterprise terms, no training on client data), managed database, monitoring, SMS, pen test.

Why not buy a skills platform?

Procurement, security review and data migration don't fit in 12 weeks. Integrating keeps exit options open, and IRIS's method is the differentiator.

So what

Nothing is migrated in 12 weeks, so the real work is integration and frontline sign-in (amber), not a platform change.
