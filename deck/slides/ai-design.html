AI

The AI only selects from approved content and the employee's own record, so it cannot invent courses, rules or scores

How the coach answers a question

1

Knows who is asking. Sign-in identifies the employee; the coach sees only their own role, skill-check results, plan and progress, never pay or colleagues (server-side access control).

2

Safety check first. Rules block colleague data, pay and promotion, prompt injection, wellbeing and crisis topics; ID, phone and email are masked (guardrail layer 1).

3

Finds approved sources. Searches lessons and policies in Thai and English (keyword search with Thai word segmentation; semantic search in production).

4

Answers with citations. A second check confirms intent, then the answer cites its sources [S1]; if nothing fits, it says so (classifier + grounded answer).

5

Sensitive topics get fixed replies. These point to the manager or HRBP, the Employee Assistance Programme or the 1323 crisis line, reviewed with the client before launch.

How the learning path is built

1

Rules shortlist approved items by skill gap, level and format.

2

The AI orders them and writes a reason for each step, in Thai and English.

3

Every item is checked against real catalogue IDs, so nothing is made up.

4

The manager approves before the plan goes live.

Thai, done properly

  • Thai has no spaces between words, so search splits words first.
  • Polite register (ค่ะ / นะคะ) and common work terms kept in English (SBI, OEE).
  • Native-speaker review is a release gate.

So what

The client controls the content; the AI only selects, orders and explains it, which keeps every answer defensible to HR and the DPO.

Source: design implemented in the prototype · the live-model quality gate is not yet passed (slide 6)

The core design choice: the model chooses from a menu we control and never writes the menu. Implementation in the prototype: Clerk identity is mapped to suite_v2_memberships (Prisma/Supabase on Vercel; D1 in the Worker sandbox); retrieval is BM25 over lessons and policies with Intl.Segmenter Thai segmentation; layer 2 is an LLM intent classifier when a live model is configured; answers cite [S1..Sn] and unsupported requests abstain. Production adds multilingual embeddings and transcripts. Source constraints reduce risk; they do not prove that a live answer is grounded.
